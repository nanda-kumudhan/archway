# Archway

My personal Arch Linux setup for development work as a computer science student.

Built around Sway and Wayland, with Foot, Waybar, and Rofi. Includes my dotfiles, app preferences, and package list.

Native packages are listed in `pkglist.txt`; Flatpak apps are listed in `flatpak_list.txt`.
LocalSend is installed from Flathub:

```sh
flatpak install flathub org.localsend.localsend_app
```
